# SpeccyWall для Karabas Go / Mini / Mini G

Шестнадцать Pentagon 128 на одной ПЛИС (Xilinx Spartan-6 XC6SLX25), все на одном экране сеткой 4×4 и
выбранный на весь экран. Продолжение идеи [QuadSpeccy](https://github.com/Caasper911/karabas-go-core-quadspeccy)
(четыре машины), но машина уже не отдельный модуль: один процессор и одна шинная логика обслуживают по очереди
восемь машин, состояние каждой лежит в своей ячейке памяти (контекст).

**Состояние: первое ядро для Karabas Go, на железе ещё не проверено.** Готовы процессор на восемь машин (`tv80_oct`)
и движок восьми машин на SRAM (`zx_oct` + `sram_ctrl`): в симуляции совпадают с восемью эталонными машинами такт в
такт. Ядро `src/speccywall.kg` (только Go): восемь Pentagon 128, на экране выбранная машина целиком — 720×576 или
1280×800 (48,88 Гц), сетки 4×4 ещё нет. План в [docs/PLAN.md](docs/PLAN.md), устройство в
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Первое ядро (Go)

- На экране стена: восемь машин в сетке 4×4 на весь экран 1280×800 (два нижних ряда пока серые), paper каждой
  1:1, вокруг её бордюр (32 точки по бокам, 4 строки сверху и снизу), край выбранной мигает. Win+` — выбранная на весь экран и обратно.
- Win+1..8 — машина (клавиатура, звук), Win+стрелки — соседняя (4 столбца × 2 ряда).
- OSD: Video 1280×800 (по умолчанию) / 720×576 (только полный экран; Menu+V — если монитор не покажет 1280×800), Side stripes
  (полосы в 1 точку по бокам в 1280×800 — подстроить фазу монитора), джойстики, AY ABC / ACB, NMI (F11), Reset
  выбранной (F12), Reset All (Menu+F12).
- В 1280×800 машина показана ×3 (1056×798), по краям экрана серая рамка в 1 точку: видна вся — монитор показывает
  растр целиком.

## Что задумано

- 16 машин Pentagon 128 (128 КБ, без 1024 КБ Profi), общий ROM 128 / 48 в блочной памяти.
- Экран 1280×800, кадр 48,88 Гц, привязанный к кадру Pentagon: сетка 4×4 с paper 256×192 каждой машины в 1:1 и
  бордюром в 1 пиксель; выбранная машина на весь экран с масштабом 3.
- Клавиатура и звук (beeper, один AY) — у выбранной машины. Без DivMMC / SD-карт и без мыши.
- Память: все 16 машин в SRAM (2 МБ из 4, есть на всех трёх платах).

## Структура

- `src/rtl/tv80/`: процессор tv80 (из karabas_go_v6z80p через QuadSpeccy) и `tv80_oct.v` — один tv80 на восемь
  CPU; `tv80o_core.v` / `tv80o_reg.v` генерирует `tools/mkctx.py` из `tv80_core.v` (не править руками).
- `src/rtl/zx/zx_oct.v`: восемь Pentagon 128 на одном CPU и одной шинной логике; `src/rtl/mem/sram_ctrl.v`: SRAM.
- `src/rtl/speccywall.v`, `karabas_go_top.v`: ядро и плата; `src/rtl/video/`: экран выбранной машины (`zx_scr.v`) и
  вывод VGA на пиксельном клоке (`vga_out.v`); `src/rtl/hid/`, `src/rtl/sound/`: клавиатура и AY из QuadSpeccy.
- `src/Makefile`, `karabas_go.{prj,xst,ucf,ut}`, `core.json`: сборка (`cd src && make go`, нужен
  `../karabas-go-tools` рядом).
- `src/sim/run_tv80o.sh`: тест `tv80_oct` против восьми `tv80_core` такт в такт (ISim из ISE 14.7).
- `src/sim/run_wall.sh`: восемь машин `zx_oct` на модели SRAM против восьми эталонных (`ROM=1` — ROM 128, снимок
  экранов).
- `src/sim/run_video.sh`: экран выбранной машины, каждая точка VGA против памяти (`MODE=0` — 720×576).
- `src/test/run_timing.sh [cpu8|wall8]`: пробная сборка на XC6SLX25, ресурсы и тайминг.
- `modules/`: общие модули Karabas Go (сабмодуль karabas-go-modules).

```sh
git clone --recursive <repo>      # или git submodule update --init
src/sim/run_tv80o.sh              # эквивалентность, 2 млн тактов (SEED=<n> — другой случайный поток)
src/sim/run_wall.sh               # восемь машин против эталона; ROM=1 ./run_wall.sh 4587520 — 8 кадров ROM 128
src/test/run_timing.sh wall8      # пробная сборка движка
src/sim/run_video.sh              # видео 1280×800 (MODE=0 — 720×576)
cd src && make go                 # ядро для Go: speccywall.kg
```
